# Using RoveSoSimulator

## Keybinds

| Key | Action |
|---|---|
| T | Toggle TeleOp drive (driving with keyboard) |
| Q / A | Forward / back for left wheels |
| E / D | Forward / back for right wheels |
| Space | Flip rover |
| R | Reset rover |
| J | Set spawnpoint |
| H | Teleport to spawnpoint |
| P | Toggle pointcloud visibility |
| F | Toggle ultrasonic box |
| L | Clear path line |
| M | Multiplayer menu |
| B | Basestation menu |
| N | Level options menu |
